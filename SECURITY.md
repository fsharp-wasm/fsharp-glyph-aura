# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.x     | ✅ active |

## Reporting a Vulnerability

**Do not open a public GitHub Issue for security vulnerabilities.**

Please use [GitHub's private vulnerability reporting](https://github.com/fsharp-wasm/fsharp-glyph-aura/security/advisories/new)
(or see the organisation's [security policy](https://github.com/fsharp-wasm/.github/blob/main/SECURITY.md) if that is not available) with:

1. A description of the vulnerability.
2. Steps to reproduce.
3. Potential impact.

You will receive a response within a week. We follow responsible disclosure
and will credit reporters in the release notes.
